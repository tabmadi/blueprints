# Agent guide

Read [README.md](README.md) first. Its [Conventions](README.md#conventions) section is the rule set for every submodule.

- A change to a convention starts in its source repo. Then apply it to every repo of the same size in the same pass. Never leave one repo out.
- Each submodule has its own `AGENTS.md`. Read it before you change that repo.
- Commit inside each changed submodule first, then commit the new pointers here. Never push.
